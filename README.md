# Subang Philippines Website

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Add `subangphilippines.org` under Project Settings → Domains after the domain is registered.

## Before launch

- Replace draft impact figures with verified data.
- Add the official logo and approved brand colors.
- Replace placeholder stories with actual content.
- Configure the official email address.
- Add privacy policy, accessibility statement, and social links.
