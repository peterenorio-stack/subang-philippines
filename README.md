# Subang Philippines Website

Built for Next.js 15.5.26 + Tailwind CSS.

## Branding
- Font: Manrope
- Maroon: #470112
- Gold: #FFB401
- Blue: #00619F
- Green: #045B01

## Uploading images
Place files in:
- `public/assets/logo/`
- `public/assets/press/`
- `public/assets/stories/`
- `public/assets/team/`

Then update the filenames in `app/content.ts`.
